Privacy Policy

Let’s Achieve Shorts · Last updated 12 October 2026

Let’s Achieve Shorts is the publishing tool of the Let’s Achieve YouTube channel. It renders General Knowledge quiz videos and uploads them to that channel. Only the channel’s owner uses it.

Google and YouTube data

The tool uses the YouTube API Services. It asks for one permission, “Manage your YouTube videos” (the youtube.upload scope), and uses it only to upload new videos, with their titles, descriptions and tags, to the channel owner’s own channel. It does not read, store or share any other Google account data, and it does not access other people’s data.

The access token Google issues is kept as an encrypted secret in the project’s GitHub Actions settings, used only by the automated publishing job, and never shared or sold.

Viewers and visitors

The tool collects no information about viewers. This website uses no cookies, analytics or tracking.

YouTube and Google policies

By using this tool you agree to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time from your Google Account’s third-party connections page. Revoking it stops all uploads.

Contact

Questions about this policy: open an issue on the project’s GitHub page.
